第18题　夹球与转动薄板｜受力与约束交互
操作：拖动蓝色 A 点沿虚线圆弧转动薄板。三个力始终从球心出发；G竖直向下，N墙水平，N板垂直薄板。力值变化时箭头连续伸缩。

实时物理量

夹角 α30°N板 / mg—N墙 / mg—G / mg1.000球心高度 y/R—
物理模型
球同时与竖直墙、薄板接触，薄板缓慢转动，按准静态平衡处理：N板·sinα=mg，N墙=N板·cosα。因此 N板=mg/sinα，N墙=mg·cotα。
验收
✓ A只能沿固定半径圆弧移动。
✓ 球的位置由接触约束计算。
✓ 三个力从球心出发。
✓ 力方向随约束实时更新。
✓ 箭头长度∝力大小，但线条保持教材式细矢量。
✓ α增大时N板、N墙均减小。
