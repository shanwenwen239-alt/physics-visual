Q18 · 平行板电容器

恒压电源 + N 板接地 + 负电小球悬浮

初始状态下小球静止，因此重力与电场力平衡。点击 A～D，观察极板几何变化后 电场强度 E、P 点电势 φP、极板电荷量 Q以及小球是否仍能悬浮。

初始关系

N 板接地，φN=0
电源恒压
小球−q，静止
受力平衡Fₑ = mg
电场方向M → N（向下）

当前变化

初始：两板间距 d 不变，电压 U 不变，因此 E=U/d。负电小球受到向上的电场力，与重力平衡。

量的变化

板间距 d不变
场强 E不变
电容 C不变
电荷量 Q不变
P 点电势 φP不变
小球状态静止

关键公式

U = 常量，  E = U/d
C = εS/d，  Q = CU
N 接地：φN = 0
