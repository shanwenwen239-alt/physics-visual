第21题　动滑轮：B → C → D
物理核查：轻绳不可伸长、滑轮光滑，同一根绳两侧张力相等。平衡时，两侧水平分力必须互相抵消，因此两段绳关于竖直方向对称。这里严格同时满足“总绳长不变”和“水平分力平衡”。

关键几何：设固定端 A 与活动端 E 的水平距离为 D，总绳长为 L。平衡要求两段绳关于竖直线对称，因此 sinβ=D/L，θ=2β。
严格关系：
2T cosβ=mg → T=mg/(2cosβ)。
B 与 C 的水平坐标相同，所以 D 相同 → β、θ、T 都相同。D 点更靠右，水平距离增大 → β 增大 → θ 增大 → T 增大。
结论：θ₁=θ₂<θ₃，F₁=F₂<F₃。对应选项 B、D。
